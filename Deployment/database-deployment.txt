NUTRIFIT PROJECT — DATABASE DEPLOYMENT (Azure SQL)

STEP 1: Create Azure Account

* Go to https://portal.azure.com
* Sign in or create a free Azure account

STEP 2: Create Azure SQL Database

1. Search for "SQL Database" in Azure portal
2. Click "Create"
3. Select subscription and resource group
4. Enter database name (e.g., NutrifitDB)
5. Click "Create new server"
6. Enter:

   * Server name (unique)
   * Admin username
   * Password
   * Region (nearest location)
7. Choose Basic pricing tier
8. Click "Review + Create"
9. Click "Create"

STEP 3: Configure Firewall

1. Open the created SQL server
2. Go to Networking / Firewall settings
3. Add your IP address
4. Enable "Allow Azure services"
5. Save changes

STEP 4: Connect Using SQL Server Management Studio (SSMS)

* Server name: yourserver.database.windows.net
* Authentication: SQL Server Authentication
* Use admin username and password

STEP 5: Import Local Database
Option A: Generate SQL Script

* Right click local database
* Tasks → Generate Scripts
* Select schema + data
* Run script in Azure SQL database

Option B: Use Import Data-tier Application (.bacpac)

* Export database as .bacpac
* Import into Azure SQL

STEP 6: Verify Tables and Data

* Check all tables
* Test queries
* Confirm data integrity

Database deployment completed successfully.
