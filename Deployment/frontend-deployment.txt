NUTRIFIT PROJECT — FRONTEND DEPLOYMENT (React on Azure)

STEP 1: Build React Project

* Open project in VS Code
* Run command:
  npm install
  npm run build

STEP 2: Create Azure Static Web App

1. Go to Azure portal
2. Search "Static Web Apps"
3. Click "Create"
4. Connect GitHub repository
5. Select branch
6. Build preset: React
7. App location: /
8. Output location: build
9. Click Create

STEP 3: Manual Deployment (Alternative)

* Create Azure App Service
* Upload build folder via FTP or ZIP deploy

STEP 4: Configure API Endpoint

* Update React environment variables
* Add backend API URL
* Rebuild project

STEP 5: Test Frontend

* Open deployed URL
* Verify UI loads
* Check API integration

Frontend deployment completed successfully.
