NUTRIFIT PROJECT — BACKEND DEPLOYMENT (ASP.NET Web API on Azure)

STEP 1: Prepare Backend Project

* Open ASP.NET Web API in Visual Studio
* Update connection string to Azure SQL database
* Test project locally

STEP 2: Create Azure App Service

1. Go to Azure portal
2. Search "App Service"
3. Click "Create"
4. Select:

   * Publish: Code
   * Runtime stack: .NET
   * Operating system: Windows
5. Choose resource group
6. Create new App Service plan
7. Click "Create"

STEP 3: Publish from Visual Studio

1. Right click project → Publish
2. Select Azure → App Service
3. Choose created App Service
4. Click Publish

STEP 4: Configure App Settings

* Open Azure App Service
* Go to Configuration
* Add connection string for Azure SQL
* Save and restart app

STEP 5: Test API

* Copy deployed URL
* Test endpoints using browser or Postman
* Ensure database connection works

Backend deployment completed successfully.
