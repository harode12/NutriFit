NUTRIFIT BACKEND DEPLOYMENT USING AZURE

Step 1: Prepare Backend Code
- Ensure backend runs locally
- Update database connection string
- Use environment variables for secrets

Step 2: Install Azure CLI
- Download Azure CLI
- Run: az login

Step 3: Create App Service
- Azure Portal → Create Resource
- Select "App Service"

Step 4: Configure App Service
- Name: nutritifit-backend
- Runtime: Node.js / Java / Python (choose your backend)
- OS: Linux
- Region: same as database

Step 5: Deploy Backend
Option A: Using GitHub
- Connect GitHub repository
- Select backend branch
- Enable continuous deployment

Option B: Using Azure CLI
- az webapp up --name nutritifit-backend

Step 6: Configure Environment Variables
- App Service → Settings → Configuration
- Add:
  - DB_CONNECTION_STRING
  - API_KEYS
  - SECRET_KEYS

Step 7: Enable CORS
- App Service → CORS settings
- Allow frontend domain

Step 8: Test Backend API
- Open backend URL
- Test API endpoints

Backend deployment completed.
